# Mobile Design References & Benchmark Gallery

This directory contains real, official production app store screenshots from benchmark apps that embody clean, high-craft, light-mode product design.

---

## 1. Things 3 (Cultured Code) — Light Mode Minimalist Benchmark
- [things3_01_today.png](./things3_01_today.png) — Clean header, generous whitespace, understated typography.
- [things3_02_tasks.png](./things3_02_tasks.png) — Task breakdown with subtle tags, checkboxes, and clean list hierarchy.
- [things3_03_projects.png](./things3_03_projects.png) — Sectioned project views without heavy borders or saturated colors.

**Key Design Lessons:**
- Soft `#FAFAFA` / `#F8FAFC` background with crisp white surfaces.
- Bold, confident typography with high contrast (`#0F172A`).
- Zero emoji clutter; subtle monochrome iconography.

## 2. Linear Mobile — Issue & Triage Triage Design
- [linear_01_inbox.png](./linear_01_inbox.png) — High-density, scannable list items with subtle status badges.
- [linear_02_issue_props.png](./linear_02_issue_props.png) — Property inspector and status chips.
- [linear_03_composer.png](./linear_03_composer.png) — Minimalist modal composer with focused inputs and direct action buttons.

**Key Design Lessons:**
- 1px subtle hairline borders (`#E2E8F0`).
- Compact, scannable metadata tags.
- Direct, clear primary buttons.

---

## 3. Stripe Dashboard Mobile — Trust, Clarity & Financial Feeds
- [stripe_01_dashboard.png](./stripe_01_dashboard.png) — Clean metrics, clear labels, calm visual balance.
- [stripe_02_payments.png](./stripe_02_payments.png) — Customer and transaction feed with clean status indicators.
- [stripe_03_details.png](./stripe_03_details.png) — Detailed transaction view with structured data rows.

**Key Design Lessons:**
- Highly legible numbers and currency formatting.
- Subtle, desaturated status badges (e.g. soft green for succeeded, soft amber for pending).
- Clear divider lines instead of heavy card shadows.
