# Git Commit Guidelines

Follow **Conventional Commits**:
`<type>(<scope>): <subject>`

### Examples:
- `feat(radar): add real-time lead score meter and urgency badges`
- `feat(autopilot): add 24/7 background responder with confidence threshold`
- `feat(paywall): integrate RevenueCat SDK with Pro & Agency tiers`
- `feat(pitch): generate grounded WhatsApp DM quotes from catalog`
- `style(theme): implement Linear dark-mode tokens and hairline borders`
